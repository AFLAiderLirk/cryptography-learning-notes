# Cryptography learning notes

An independent overview of local Python and Bash learning materials. This is not an official assignment specification and does not claim verified cryptographic implementations or completed assessments.

## Topics represented

- Hash and XOR exercises.
- Symmetric encryption and block cipher operating modes.
- RSA, Diffie–Hellman, and certificate infrastructure.
- Python experiments and a Bash PKI inspection script.

## Approach

The local materials combine small scripts, written observations, illustrations, and a test PKI directory. Cryptography exercises should use synthetic inputs and newly generated disposable test keys. Their purpose is learning; the reviewed materials do not establish production security.

## Publication scope

Only this summary is included. School statements, exact answers, scripts implementing the submitted solutions, passwords, private keys, certificates, original diagrams, conversation logs, and PKI archives are excluded. Original school publication permissions have not been confirmed.
